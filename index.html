Voice Vault

Voice Vault is a personal automation agent I built for myself. It telephones me once a day, asks how the day went, and files what I tell it into my own notes. It reads and writes events on my own Google Calendar so that it can remind me of the things I said I would do.

It has exactly one user: me. It is not a product, it is not for sale, and it has no sign-up. The privacy policy explains what it touches and what it does not.
